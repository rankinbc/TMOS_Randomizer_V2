# world_editor outputs

Run artifacts from the `world_editor` component land here as `<YYYY-MM-DD>_<run-description>/` subfolders (e.g., `2026-04-24_exported_after_boss_swap/`). Keep latest ~5; move older to `_archive/`.

Typical contents: `world.json` (simplified world state), `map_chapter<N>.png` (composited snapshots), `session_notes.md`.
