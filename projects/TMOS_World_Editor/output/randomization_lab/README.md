# randomization_lab outputs

Run artifacts from the `randomization_lab` component land here as `<YYYY-MM-DD>_<run-description>/` subfolders. Keep latest ~5; move older to `_archive/`.

Inside each run folder: `run_manifest.json`, `summary.md`, and one subfolder per strategy containing `screenshot.png`, `world.json`, `validation_report.json`, `diff_vs_pristine.json`.
